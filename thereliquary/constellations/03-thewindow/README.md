## Record Role

**The Window** is preserved as the third Constellation of Digital Antiquity.

Its domain is:

```text
Interface
```

It represents:

- Accessibility
- Visibility
- Interaction

The page frames The Window as the interface through which otherwise invisible computation and communication became perceptible to people.

---

## Preservation

The record begins from a simple premise:

> Before the digital world became familiar, it had to be seen.

The Window provides that opening.

The source describes several consequences:

- distance became visibility;
- machines became places;
- information became reachable;
- people could look into systems they could not physically enter.

The Window therefore preserves interface as the mechanism by which hidden digital systems became visible worlds.

---

## The Window Did Not Create the Digital World

The page explicitly distinguishes interface from the deeper systems beneath it.

It states:

> **The Window did not compute.**

> **It did not carry the message.**

Instead:

> **It revealed what computation and communication had made possible.**

This distinction is central to the record.

The Window does not replace computation or communication.

It makes their results visible and available for interaction.

---

## Visibility and Interaction

The record describes a transition in which:

```text
invisible structures
→ visible worlds

hidden systems
→ places of interaction
```

The Window therefore preserves more than graphical display.

It represents the emergence of an interface through which digital systems could be encountered as places.
