## Folder Standard

Transmission folders should follow this naming pattern:

```text
transmission###-title
```

Examples:

```text
transmission001-whatif
transmission002-themap
transmission003-thefrontier
transmission004-thebuilder
transmission005-theinheritance
transmission006-thebetween
transmission007-thepresence
```

Use lowercase letters, the three-digit Transmission number, and hyphens between words.

## Maintenance Rule

Whenever a Transmission is renamed, relocated, revised, or republished:

1. Update this README.
2. Update the folder name when necessary.
3. Update the page title and visible Transmission title.
4. Update the canonical URL.
5. Update Open Graph and social metadata URLs.
6. Verify all internal asset paths.
7. Verify the concealed discovery link.
8. Update the corresponding entry in **The Reliquary Ledger**.
9. Record the date last verified.
10. Preserve a redirect from the previous path when practical.

---

## Hidden-Link Preservation Rule

Each Transmission should have a complete concealed-path record in **The Reliquary Ledger**.

That record should preserve:

```text
Entry point
→ discovery trigger
→ intermediate destination, when applicable
→ next trigger, when applicable
→ final Transmission destination
```

A visible page may change over time.

A hidden path must therefore be verified whenever its source page is substantially rewritten.

---

## Media Principles

Transmissions are not required to share one format.

The medium should serve the constitutional or philosophical purpose of the individual Transmission.

Approved or previously considered forms include:

- static narrative page;
- interactive path-based experience;
- meditative scroll journey;
- cinematic or documentary video;
- minimalist visual sequence;
- animation embedded directly within HTML.

The medium should never disclose more than the Transmission is constitutionally prepared to reveal.
