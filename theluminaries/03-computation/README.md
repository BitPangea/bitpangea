## Record Role

This page preserves **Computation** as the third dependency in The Luminaries.

The record establishes the transition from symbolic representation and logical operation to a universal mechanism capable of executing those symbolic rules.

The lineage progression is:

```text
Binary
→ representation

Computation

```

The page states this directly:

> **Binary provided representation. Logic provided decision. Computation unified both into a universal model.**

## The Discovery

The record preserves **Alan Turing** through the concept of universal computation.

It identifies Turing’s 1936 description of the **Universal Turing Machine** as the relevant discovery.

The page defines that contribution as:

> a mathematical model capable of performing any computable process through a single abstract machine

The record is careful not to equate this with the invention of a physical computer.

Its significance is deeper:

> **It was the discovery of the underlying nature of computation itself.**

---

## What Became Possible

The record identifies universal computation as the conceptual basis for general-purpose computing.

Instead of requiring a different machine for every task, one machine could execute different instructions.

That opened the path toward:

- software;
- operating systems;
- programming languages;
- modern general-purpose computing.

The page therefore preserves universal computation as the condition that makes programmable computing possible.

