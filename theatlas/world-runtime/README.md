## Architectural Role

World Runtime provides the architectural home for live operational functions including:

- execution;
- synchronization;
- communication;
- routing;
- shared services;
- other operational capabilities.

Its purpose is to keep these functions structurally distinct from:

- permanent spatial truth;
- Parcel identity;
- other enduring architectural records.

This separation allows runtime systems to evolve without rewriting the World beneath them.

## Governing Direction

The source defines the domain’s governing direction as deliberately bounded.

Runtime should:

- enable function without defining permanent place;
- remain replaceable and evolvable;
- depend upon the World’s permanent architecture.

Operational systems may:

- change;
- be replaced;
- be distributed;
- be upgraded;
- be reimplemented.

Those changes should not alter:

- canonical spatial truth;
- Parcel identity;
- durable architectural meaning.

The source states:

> **Runtime should depend on the World’s permanent architecture; the permanent architecture should not depend on any one runtime.**
