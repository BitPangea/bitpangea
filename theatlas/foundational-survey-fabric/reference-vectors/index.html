Reference Vectors

Foundational Survey Fabric · Canonical Test Corpus Framework

The canonical examples and test cases through which expected Foundational Survey Fabric results become independently reproducible.

Foundational Survey Fabric Reference Vectors define the exact input-and-expected-result cases that will allow independent implementations to prove agreement with the governing Specification and Conformance framework.

Reference Vectors do not select the Survey mathematics. The Requirements establish what must be satisfied. The Specification defines the mathematics that satisfies those requirements. Conformance defines how an implementation proves compatibility. Reference Vectors then provide canonical examples, negative cases, and adversarial tests against which that implementation can be evaluated.

Because the final Survey mathematics are not yet selected, these pages establish the required vector categories and proof obligations rather than inventing authoritative input/output data prematurely.

Together, these twelve sections define the intended canonical test architecture for the Foundational Survey Fabric: address resolution, Survey Domain limits, Pang measurement, orientation, geometry, normalization, transformation, precision, invalid-input rejection, serialization, version and conformance behavior, and deliberate pathological stress.

The Reference Vector corpus remains subordinate to the governing Requirements, Specification, and Conformance framework. It may prove, expose, compare, and reproduce expected behavior, but it may not invent spatial truth, fill unresolved mathematical gaps, or override the canonical rules established by the Specification.

Architectural Sequence Requirements establishes what must be satisfied. Specification defines the mathematics that satisfies it. Conformance defines how an implementation proves it follows the Specification. Reference Vectors provide canonical examples and test cases proving the expected results.
