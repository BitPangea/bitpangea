# VIII. Boundary Tests

A proposed Survey Fabric responsibility should be rejected or moved upward if it fails any of these tests.

### Identity Test
Does the rule identify **what an entity is**, rather than where canonical space is?

### World Membership Test
Does the rule determine whether referenceable space is **part of The World**?

### Semantic Boundary Test
Does the rule decide **what a boundary means**, rather than merely how exact geometry meets?

### Rights Test
Does the rule decide who owns, controls, accesses, governs, or may act?

### Terrain / Surface Test
Does the rule add elevation, terrain, visible Surface, built form, or experiential morphology?

### Temporal Test
Does the rule encode history, occupancy, state transition, provenance, or time into canonical place?

### Runtime Test
Does canonical place depend on live execution, synchronization, or operational state?

### Experience Test
Does the rule define how space is rendered, navigated, perceived, or experienced?

### Implementation Test
Does one grid, library, database, cryptographic system, or software implementation become the source of canonical meaning?

If yes, the responsibility belongs above the Foundational Survey Fabric or violates its architectural boundary.
