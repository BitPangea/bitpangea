## Purpose of This Space

The Parcel Cadastre exists to give each Parcel a durable spatial identity independent of:

- who owns it;
- how it is rendered;
- what is built upon it;
- which implementation serves it.

The source identifies it as the authoritative home for:

- the fixed Parcel population;
- the spatial facts that make one Parcel permanently distinguishable from another.

---

## Governing Direction

The source defines the domain’s governing direction as deliberately bounded.

The Parcel Cadastre should preserve:

- Parcel identity;
- position;
- territorial extent;
- other irreducible cadastral facts.

It should not absorb:

- ownership;
- access rights;
- economic state;
- infrastructure;
- services;
- experience.

The Cadastre should depend upon the demonstrated spatial foundation beneath it rather than redefine that foundation.

Changes above the Cadastre should not alter the permanent meaning of an established Parcel.
