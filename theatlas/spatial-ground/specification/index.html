Spatial Ground · SG-SPEC-1.0 Adopted

The adopted formal rules by which valid canonical Survey space receives one exact Spatial Ground membership result.

The Spatial Ground Specification defines how the adopted Spatial Ground Requirements are satisfied through the Canonical Membership Predicate Model (CMPM). It governs World-membership semantics, input validity, the Foundational Survey Fabric dependency contract, canonical definition rules, deterministic evaluation, representation independence, reconstruction, and the machine-readable Ground Definition profile.

The primary normative artifact is SG-SPEC-1.0. This page explains that Specification; it does not become an independent source of Spatial Ground semantics.

Governing Layer Relation FSF supplies canonical spatial reference and mathematics. Spatial Ground adds canonical participation in The World.

Formal Model

Membership Predicate

For every valid canonical Survey location, the adopted Ground Definition yields exactly one canonical result: WORLD or NON_WORLD.

M_D : S → {WORLD, NON_WORLD}

Canonical World-Space

World-space is the semantic set induced by the governing Ground Definition, not a separately authored registry or higher-layer interpretation.

W_D = { x ∈ S | M_D(x) = WORLD }

Input Validity

FSF validity and canonicalization occur before Ground membership evaluation. Invalid Survey input is rejected and is not interpreted as NON_WORLD.

Implementation Independence

No implementation is canonical. Independent conforming implementations must produce identical canonical results for identical canonical inputs.

Adopted FSF Dependency

Survey Authority

FSF-SPEC-1.0 supplies canonical reference, frame, coordinates, Pang measure, Point / Segment / SCPE geometry, exact predicates, deterministic normalization, refinement semantics, and compatible lineage.

Canonical Bounds

H = 1,000,000 Pang; S = [-1,000,000,+1,000,000]²; P = [-500,000,+500,000]².

World-space ⊂ interior(P) ⊂ interior(S)

Canonical Representation

Ground Definition

The canonical machine-readable Ground Definition representation is SG-CJSON 1.0. The selected production profile uses one primary FSF spatial-set definition through one fsf root.

Geometry Interchange

Canonical exact Survey geometry remains governed by FSF-CJSON-1.0. Spatial Ground references that geometry rather than duplicating it into a competing Ground-owned grammar.

Production Profile

Unrestricted Boolean / composite-result closure remains outside the current production profile. Historical synthetic operators do not expand the adopted FSF capability surface.

Primary Normative Artifact

The adopted Specification remains the authority for Spatial Ground semantics.

Specification Boundary

Spatial Ground introduces canonical World-membership meaning only. It does not define Parcel identity, Parcel eligibility, ownership, rights, Regions, terrain, visual World Form, settlement, economics, culture, experience, or any other higher-layer meaning.

Conformance proves implementation compatibility with the adopted Specification. Reference Vectors demonstrate the Specification. Neither may create missing Specification mathematics or independent canonical authority.

Specification Principle Reference Vectors demonstrate the Specification. They do not create the Specification.
