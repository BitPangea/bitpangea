# Spatial Ground — Instance Design

This directory contains the current Creator-period design artifacts for the BitPangea World-space instance.

The active scaffold and boundary candidate files in this directory are the **visual-lineage-based redraw set**, derived from the established BitPangea silhouette reference.

These files remain **non-canonical design artifacts** until the World-space instance is formally adopted.

Earlier abstract geometric candidates have been preserved under:
