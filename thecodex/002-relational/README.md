## Purpose

The source states that the Relational Domain establishes the first-order relational grammar through which structural concepts may be described in relation to one another.

It preserves:

- relation;
- connection;
- measure;
- orientation.

The source explicitly states that the Domain does so without assigning:

- ownership;
- jurisdiction;
- access;
- value;
- purpose;
- movement;
